# Mission 1 — Know your computer

## 1. Task / objective
Explain input, processing, output, and storage (IPOS); classify hardware and software; and describe everyday computer-based systems.

## 2. Work completed
### Task 1.1 — IPOS example: writing and saving a document in VS Code

| Stage | What happens? | Component |
|---|---|---|
| Input | I type text and use the Save command. | Keyboard; mouse or trackpad |
| Processing | The computer handles keystrokes and updates the document in memory. | Processor (CPU) and RAM |
| Output | The text and editor controls appear on screen. | Display |
| Storage | Saving writes the document to the selected storage location. | SSD or other selected storage |

The keyboard supplies the text, the processor and memory handle the current work, the display shows the result, and saving stores a persistent copy.

## 4. My understanding
IPOS is a useful way to trace a computer task from the user's action to a saved result. Hardware is the physical equipment, while software is the set of instructions that runs on it. The operating system manages the computer, applications help users complete tasks, and utilities help maintain or manage software.
